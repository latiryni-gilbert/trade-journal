# Trade Journal

This is a trading journal that can be used to track habits, win rate, P&L per setup, position size, and goals.

## Why I'm building this

Looking through my own exports, I found habits I hadn't noticed while trading. My position sizes would jump after losses due to revenge trading. I would also spam entries to try and hit big wins in seconds to account for the losses. This journal will help me notice my mistakes, correct them, and build discipline along the way.

## Status

Phase 0: building a command-line tool that reads broker CSV exports and turns raw fills into complete trades.
